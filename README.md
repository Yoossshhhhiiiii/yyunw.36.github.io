# 富士山・三張明信片

這個倉庫包含可直接部署到 GitHub Pages 的靜態網站。點選明信片會顯示對應的旅途文字並播放音樂；關閉文字視窗會停止播放。

## 檔案

- `index.html`、`styles.css`、`script.js`：網站頁面與互動。
- `captions.json`：三張明信片對應的文字。
- `assets/summit.png`、`assets/sunrise.png`、`assets/torii.png`：依原始照片生成的明信片圖片。
- `assets/desk.png`：手繪木桌背景。
- `assets/postcard-song.mp3`：點選明信片時播放的使用者提供音樂。

網站使用相對路徑，可從倉庫根目錄由 GitHub Pages 發布。
